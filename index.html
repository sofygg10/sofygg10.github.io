P/03

Furl Life — Avatar Matching

API REST en Node.js / Express que convierte la foto real de una mascota en un avatar ilustrado tipo Pixar / Dreamworks. Combina Google Cloud Vision para detectar especie, raza, color y etapa de vida, un catálogo local con matching difuso (Levenshtein) y un fallback de generación con FLUX vía Pollinations.ai.

Ver detalles

Pipeline de 5 etapas

  • Reconocimiento · Google Vision (LABEL_DETECTION) etiqueta la foto
  • Normalización · diccionarios convierten labels a {species, breed, color, stage} con sinónimos y blocklist de contexto
  • Match en catálogo · Levenshtein sobre assets/avatars/; si confianza > 0.80 responde sin llamar a IA
  • Fallback con IA · genera con FLUX vía Pollinations.ai usando un prompt dinámico estilo Pixar/Dreamworks
  • Caché auto-poblante · doble escritura (historial + catálogo): el sistema se vuelve más rápido y barato con el uso

Objetivo

Entregar avatares estilizados y consistentes que reflejen los rasgos reales de cada mascota en segundos, sin pagar un ilustrador ni intervención manual.

Decisiones técnicas

Resolución de raza por capas (exacta → substring → keywords → fallback a "criollo"), lógica dedicada para gatos naranjas (branding del producto), logs trazables por etapa ([Vision], [Match], [Cache]) y diseño para Oracle Cloud con load balancer y health check.

Resultados

Endpoint POST /api/avatar/match devuelve source, imageUrl, matchedAttributes y confidence. Cada generación enriquece el catálogo, reduciendo costos y tiempos de respuesta futuros.

P/04

FurLife — Asistente IA "Luna" en n8n

Workflow en n8n que expone un asistente conversacional con Google Gemini y un sistema proactivo de recordatorios diarios para citas veterinarias del día siguiente.

Ver detalles

Funciones

  • Chat reactivo vía webhook con memoria por session_id
  • Tool calling: Google Calendar + búsqueda web (Serper)
  • Action codes que indican al frontend qué pantalla abrir
  • Recordatorio diario a las 8 AM por Gmail
  • Redacción cariñosa con emojis 🐾 generada por un segundo agente
  • Infra local con Docker Compose

Objetivo

Dar al vertical de mascotas un asistente conversacional barato y rápido que además avise proactivamente al dueño cuando su mascota tiene cita al día siguiente.

Retos

Desacoplar IA y frontend mediante action codes estables, mantener memoria por usuario y orquestar dos flujos (reactivo + proactivo) en el mismo canvas sin acoplarlos.

Decisiones técnicas

Gemini Flash por latencia y costo, memoria por session_id y separación del JSON del texto en un nodo de código para que la app reaccione a códigos estables aunque el modelo varíe su redacción.
